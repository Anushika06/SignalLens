Trust by design

How sure are we? Rules decide — not the model.

Five evidence statuses, computed by code

  • Confirmed

    A primary source supports it: the company’s own site, the issuing regulator or a statutory registry.

  • Corroborated

    No primary source, but two or more independent publishers agree and none contradict.

  • Single source

    Exactly one independent publisher. Severity is capped below Critical.

  • Conflicting

    Primary sources disagree or contradict the claim — or independent reports clash with no primary source to settle it.

  • Unverified

    No verified supporting evidence yet. Severity is capped at Medium.

Evaluated in a fixed order, conflict first; the first match wins. Syndicated copies count once; forums never move the status.

  • Quotes checked word for word

    Evidence counts only if its quote is found in a page the agent actually opened. Changed numbers fail.

  • Facts kept apart from interpretation

    The assessment is labelled as the agent’s and lists its assumptions.

  • Web pages can’t give orders

    Fetched text is treated as data. Research tools are read-only.

  • Humans approve anything external

    Sharing outside the company, external email and webhooks wait for a person.

SignalLens6 / 14

The model does two narrow things: it copies a quote from a page it actually opened, and it labels the quote as supporting, contradicting or context. Code does the rest — it checks every quote against the retrieved text and computes the status from fixed rules.

Nobody can defend “94% confident” in a meeting. Anyone can check “Confirmed — Razorpay’s official pricing page; no contradicting sources.” Research is autonomous; anything that leaves the company needs a person.
